# Integerated-Universal-Precision-Power-Supply
Designing a precision power board in EasyEDA as the base for a measurement system: USB C and DC input with LM66100 ideal diode ORing, TPS6216x buck rails, an LT8330 boost and TPS63700 inverter feeding LT3042/LT3094 LDOs for clean ±5V and 3.3V analog rails, and a buffered REF5025 2.5V reference.
